How it will work

  1. It fires once, when all six weeks are complete, and after the Week 6 recognition card.
  2. It goes through the same path as every other cohort recognition, so the same safety checks apply (test accounts never post, errors are logged).
  3. It is signed by the member's own coach, by name (e.g. "From Rebecca Louise", "From Sinead"). Only you, as the top of the tree, would be signed "AI Wellness Team".
  4. It has its own one-time key (simona:cohort_complete:cohort-one), so it can never post twice, even if a week is ticked again.
  5. It lands in that member's cohort tab (Cohort One, or Cohort Two later) and they get the usual notification.
  6. The member's own "All six weeks, done" pop-up on Home stays exactly as it is. This adds the public celebration in Community.

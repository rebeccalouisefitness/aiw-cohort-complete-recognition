How it will work

  1. One path. It is written by the same function as every cohort card, private.post_week2_recognition, through a new 'cohort_complete' branch. So it gets the same safety checks: test accounts never post, and errors are logged.
  2. Once, after Week 6. It posts when all six weeks are complete, straight after that member's Week 6 card.
  3. Can never post twice. It has its own one-time key, <slug>:cohort_complete:<cohort_id> (for example simona:cohort_complete:cohort-one), so ticking a week again does nothing.
  4. From the coach, by name ("From Rebecca Louise", "From Sinead"). Only your own card, at the top of the tree, would say "AI Wellness Team".
  5. Notifications. 'cohort_complete' is added to notify_community_recognition, so the member gets the usual notification. It is also added to cohort_wins_launch_guard, so it lands in the right cohort tab (Cohort One now, Cohort Two later).
  6. The app ships the new card before the database change goes live. An older app shows it as a plain shout-out, which is safe. The member's own "All six weeks, done" pop-up on Home doesn't change.
